## 实现边界

### 文件、上传与一致性

- 同一文件对象实施所有者/创建者、读/写、最近共享祖先权限；列表、跨层移动、复制、删除、恢复、分享、协作附件、搜索和DAV复用ACL。恢复历史需要写权限，分享链接变更需要写权限，修复源只读用户可变更内容/guest标志的越权分支。
- 文件系统保存不可变SHA-256路径；流式计算大小/MD5/SHA-256；临时文件fsync之后原子replace，再插入DB引用。回滚最多留下不可达字节，不会提交引用到半文件。历史保存完整真实字节；不覆盖旧版本。全命名空间锁使用单个InnoDB行，代码标记吞吐上限和未来按owner分片方向。
- 上传持久会话包含用户、场景参数、精确size/hash、received映射、有效期和结果。分片按5MiB且末片精确长度校验；merge流式拼接后核MD5/总大小；同事务锁定会话，成功结果可幂等读回。四场景为文件柜、聊天/任务附件、真实Pillow图片、通用文件。秒传只复用同用户命中文件且仍经目标目录授权。
- 私有字节不在静态目录。随机能力URL对应数据库grant，文件/ZIP读取复验发起人当前权限，聊天grant绑定dialog；撤权/停用后拒绝。Office仅签外网同源或原前端固定`http://nginx`内部origin上的精确获授权API路由，支持只读guest分享/消息/任务附件；下载固定到配置服务origin且禁止重定向，回调HS256签名验证后保存。
- ZIP作业真实生成ZIP并发布下载grant，进度经outbox持久投递，完成经真实系统bot对话模板发送；合法bot缺失会持久失败，不绕许可造账号。
- 嵌入文档/报告的base64图片经过真实Pillow字节验证并原样持久，不生成假图片或临时失效图片URL。没有把源图片URL形态完全保真称为像素验收。
- 临时表、过期upload/download/lock、DAV审计和已过保留期的回收站元数据有真实清理。**不可变blob保守保留**，包括回滚孤立blob；当前没有引用计数回收器，避免误删历史/跨消息引用。这是明确的磁盘空间限制，不标为字节垃圾回收完成。

### WebDAV

- `OPTIONS PROPFIND GET HEAD PUT DELETE MKCOL MOVE COPY PROPPATCH LOCK UNLOCK`；XML207、属性200/404/403/424、URI Unicode编码、Depth、Destination、If tagged/untagged布尔列表、If-Match/If-None-Match、Overwrite、Lock-Token、Timeout。
- 根命名空间`files`/`shared`，共享根名称`name [#id].ext`。虚拟根禁止写入；共享根禁止移动/删除。GET/HEAD/Range交给实际Starlette FileResponse，不把文件读进JSON。
- 基于同一file_id保存锁，避免`files`和`shared`两个URI绕锁。普通文件柜写也检查DAV锁。死属性按file_id和用户保存，COPY复制属性，MOVE保留，DELETE清除。覆盖在DB事务内，失败回滚命名空间和metadata，字节不可变。
- PROPFIND无限深返回RFC允许的403 `propfind-finite-depth`，不递归无限树；COPY支持0/infinity并有节点硬上限。
- 专属随机应用密码经共享密码哈希验证，显式TLS要求；凭据撤销清锁，过期/停用拒绝；持久限速、使用记录、成功及失败审计。不接受代理头自行宣称TLS，部署应由可信ASGI代理配置处理。
- 尚未经过第三方DAV客户端互操作性验收；特别要验证共享锁、tagged If、Range多段、HEAD和重命名后的属性/锁。

### 报告与搜索

- 11个报告方法：本人/接收列表筛选、发送/编辑、真实项目任务生成日/周报、可变表头labels/datas、详情/阅读/未读、每查看者AI分析存储、分享真实对话。报告模板复用shared Jinja模板，任务/项目/负责人文本转义后才标记生成HTML。
- 报告签名使用所选日期/ISO周；明确修复原daily偏移仍用today而重复提交的问题；新数据库无旧sign互通义务。作者修改、接收人访问、分享码和分析授权显式区分。
- 搜索5类查询，已安装Manticore时真实HTTP SQL/replace、向量embedding与RRF；未安装时走源约定MySQL回退；已装但缺URL报错而非悄回退。每个结果使用当前MariaDB ACL复核，索引权限过期不能扩大访问。
- `search.initialize/rebuild/sync`是真实作业，索引仅操作`backend_*`自有表；模型维度/模型URL变更会重建。`task_vector_search`供项目AI复用。启用向量需要真实Embedding服务，不用假向量。
- 文本提取：UTF-8/UTF-16/GB18030、OOXML/ODF ZIP/XML、PDF(pypdf)、XLS(xlrd)、RTF与CSV文本；DOC/PPT调用配置的LibreOffice executable转换后实际解析。外部解析进程不在本批运行。

- avatar复用shared实际Pillow+Source Han字体；shared由随机缓存深色改为确定深色，颜色不承诺源像素一致。
- Index API文档301；桌面draft/release真实文件字节与原子DBmanifest，保留最新五版/最近30天版本；发布密钥恒定时间比较；模板显示真实files/is_draft/other_version。
- Preview读取获授权真实文件，PDF inline或大文件下载模板；EEUI消息和FILEVIEW真实URL代理保留。Drawio图标请求固定官方`https://app.diagrams.net/iconSearch`。
- crontab检查真实已注册任务，入队各域真实schedule；不返回“success”掩盖缺失必需消费者。周期邮件/meeting/checkin/project/AI分别由其owner接入。
